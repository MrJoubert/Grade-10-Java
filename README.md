# Grade 10 Java Code Library

Welcome to the **Grade 10 Java Code Library** — a structured reference library designed to help you learn, understand and apply the fundamental programming concepts required in Grade 10 Information Technology.

This repository contains explanations, Java code examples, algorithms and programming techniques organised by topic. It is intended to be a resource that you can return to throughout the year when learning new concepts, completing practical programming activities and preparing for assessments.

The content is organised around the Grade 10 programming requirements of the **IEB Information Technology curriculum**, with a focus on developing a strong foundation in Java.

## Repository Contents

The Grade 10 library is divided into the following sections.

| Section | Description |
|---|---|
| **01 — Variables and Data Types** | Learn how to declare and initialise variables, use primitive data types, work with constants and follow Java naming conventions. |
| **02 — Operators and Calculations** | Understand arithmetic operators, integer division, remainders, real division and operator precedence. |
| **03 — Input and Output** | Learn how to receive input, display output and combine input, processing and output in Java programs. |
| **04 — Type Conversion and Casting** | Explore conversions between strings, numbers and characters, including widening and narrowing conversions. |
| **05 — String Manipulation** | Work with string length, concatenation, uppercase and lowercase conversion, and string comparison. |
| **06 — Boolean Logic** | Understand Boolean expressions, relational operators, logical operators, truth tables and compound conditions. |
| **07 — Selection and Loops** | Use `if`, `if-else`, `switch`, `for`, `while` and `do-while` statements to control program execution. |
| **08 — Methods and Existing Classes** | Learn to use built-in Java methods and classes, create methods, pass parameters, return values and reuse code. |
| **09 — Algorithms and Problem-Solving** | Develop computational-thinking skills using decomposition, abstraction, pseudocode, flowcharts and common algorithms. |
| **10 — User Interface and Validation** | Design clear text-based interfaces, provide appropriate prompts and messages, and validate input. |
| **11 — Testing and Debugging** | Test programs with different data, use trace tables, identify programming errors and improve program reliability. |
| **12 — Integrated Examples and Practice** | Apply your knowledge through combined programming examples, algorithm exercises and examination-style practice. |

## How to Use This Repository

For the best results, work through the library systematically.

1. **Start with the fundamentals.** Make sure you understand variables, data types, operators and input/output before progressing to more complex topics.
2. **Read the explanations carefully.** Understand what each programming concept does and when it should be used.
3. **Study the Java examples.** Follow each statement and work out how the program executes.
4. **Practise independently.** Type the examples into your Java development environment, run them and experiment with different values.
5. **Modify the examples.** Change inputs, calculations, conditions and loop structures to see how the program behaves.
6. **Use trace tables.** Follow the values of variables step by step when working through algorithms and debugging programs.
7. **Apply what you learn.** Use the integrated examples and practice sections to combine concepts in complete programs.

Do not simply memorise code. Focus on understanding the logic behind each solution so that you can apply the same principles to unfamiliar problems.

## Java Programming Conventions

The examples in this library aim to use consistent, readable Java code.

- Use meaningful variable and method names.
- Follow Java naming conventions.
- Use appropriate data types for the information being stored.
- Write one statement per line.
- Use indentation and spacing to make code easier to read.
- Include comments where they clarify the purpose or logic of a program.
- Avoid unnecessary duplication by using methods where appropriate.
- Test programs with different inputs, including boundary and abnormal values where relevant.

Input examples will generally use `JOptionPane` where appropriate for the Grade 10 programming context.

## Scope of the Grade 10 Library

This library focuses on foundational Java programming concepts and problem-solving techniques.

Topics such as arrays, searching and sorting, advanced string-processing algorithms, file processing and more advanced object-oriented programming belong to later stages of the programming curriculum and are therefore not the focus of this Grade 10 section.

The intention is to build a solid understanding of the fundamentals before progressing to Grade 11 and Grade 12.

## Important Reminder

You are encouraged to experiment with the examples, ask questions, investigate errors and develop your own solutions. Programming is a skill that improves through consistent practice.

**The goal is not just to write code that works, but to understand why it works.**
